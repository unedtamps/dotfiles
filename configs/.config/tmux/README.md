# Tmux Config

- **Plugins:** TPM, tmux-resurrect, tmux-continuum, tokyo-night-tmux, tmux-powerline, vim-tmux-navigator
- **Prefix:** `Ctrl + Space`

## Install TPM plugins

Start tmux and press `Prefix + I` (capital i).

## Key bindings

| Key | Action |
|-----|--------|
| `Prefix + r` | Reload config |
| `Alt + h/j/k/l` | Pane navigation |
| `Prefix + s` | Choose session |
| `Prefix + w` | Choose window |
| `Ctrl + Tab` / `Ctrl + Shift + Tab` | Next / previous window |
| `Super + Tab` / `Super + Shift + Tab` | Next / previous session |
